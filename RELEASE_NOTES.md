# Tomato Cut v0.12.0 — The very official button department

**[Download the FULL PACKAGE](https://github.com/coffeeANDstuff/TomatoCut/releases/download/v0.12.0/TomatoCut-Full-v0.12.0.zip)** — Windows game, complete editable Godot project, original Blender/GLB/SVG/WAV art, tests and handoff documentation.

Unzip and run **Windows/TomatoCut.exe**. **Windows/Play-Compatibility.bat** supplies OpenGL fallback. No editor/installer is required to play; open **Source/project.godot** with Godot 4.6.3 standard to continue development.

- Start/replay and primary actions now use original **tomato-seal tickets**, with clipped corners, engraved double rules, cream lettering, a serif face and offset printed shadow.
- Upgrade purchases use **green botanical order slips** with a seed seal and perforated edge. Secondary actions, category/product selectors, equipment/preparation and archive controls share the paper-label family. Selected tabs carry a printed marker/underline; disabled prices and action labels remain readable.
- Navigation uses the existing original line icons on **stamped tiles**, with current-page indications. Preferences use **checkmark/dash slips**. Confirmation actions share the new theme and retain their full reset warnings.
- Original SVG nine-slice surfaces scale across long and short buttons. Hover, press, held-hover, disabled and dotted keyboard-focus states are explicit. Native mouse/keyboard input, one-second tooltips, purchases/equipping, seed transactions, cancellations and preferences keep their existing behavior.
- **604 logic**, **182 rendered GUI** and **74 embedded-pack checks per target** pass; exact evidence is recorded in Source/TESTING.md. Windows/Linux exports, embedded packs and clean source/package validation are delivery gates.

This requested UI milestone preserves both automatic events, all existing content and schema-5 saves. The next gameplay milestone remains **The Big One / Giant Harvest**. Three events, broader permanent branches, the remaining 22 normal varieties/22 knives, mastery, achievements, environments, music and wider production polish remain. Native Windows, Forward+, audio listening, supported-PC 60 FPS and human economy pacing are unverified.
